# わかったこと・効いたこと・効かなかったこと

数値は特記なき限り、自前の対戦評価（色を交互にした1試合あたり平均得点。0.5＝互角）です。16試合で ±0.1 程度ぶれます。
乱数種の組を変えると結論が反転した例が多いため、「頑健」と書いたものは複数の種の組で確認したものに限ります。

## 1. 課題の構造（確認済みの事実）

| 項目 | 内容 | 出典 |
|---|---|---|
| 勝利条件 | 相手の護衛対象機の撃墜（`terminalAtElimination`、対象は `.*Escorted.*`）。戦闘機の全滅では終わらない | ruler.json |

## 2. 勝敗を決めているもの（診断）

1. **戦闘機戦の消耗で決まる。** 同一エージェント同士の対戦では、勝者は相手戦闘機を全滅させ、そのあと護衛対象機を落とす。負けた側は護衛対象機に1発も撃てないことが多い。
2. **結果は乱数種（初期配置・性能の割当）に強く依存する。** 同一エージェント同士では、同じ種なら色を入れ替えても勝つ色が同じ。16試合の比較は ±0.1 動く。
3. **被撃墜の約2/3は「撃ち返していない相手」から。** v9b 系の約360件の被撃墜を分類すると、被撃墜機が撃墜者を一度も撃っていない例が231件。そのうち約半数は撃墜者が機首±30°・約35 km にいた。
   - 原因1：撃墜者がレーダ航跡になく IRST のみ（射撃不能）。
   - 原因2：Pk モデルが 0.2–0.4 と悲観的で撃たず、相手が先に撃った。
4. **自機の攻撃到達が遅い。** 妨害がなければ約290–300 s で射程に入れる。しかし p2 の初弾中央値はベンチマーク相手でも 376 s。中盤（150–330 s）に仮想脅威で後退（VDRAG）し、4–9 km まで降下して減速していた。
5. **すり抜けた敵機は見えない。** 味方戦闘機の後ろへ抜けた敵機はどのセンサにも映らず、護衛対象機が撃たれる。

## 7. 評価方法についての教訓

- **局所評価は実戦の順位をよく予測しない。** 対 v7 の得点は、adapt と pk が p2 より高かったが、実戦ではどちらも下だった。スナイパー型（13.5 km、迎撃役なし、護衛対象機を早撃ち）相手の得点が最もよく一致した（adapt を除く）。
- **非推移性が強い**（じゃんけん構造）。14 km は 12 km に強く、10 km は 14 km に強い。v9b は p2 に直接対戦で勝つが実戦では下。
- **初期格付けの点数は情報が少ない。** 実戦の強さは選択して対戦を積んだ後の点数で判断する。
- 同一コード同士の対戦は種ごとに決定的（色を入れ替えても同じ色が勝つ）。比較は同じ種・両色で揃え（tools/paired.py）、2組以上の種で確かめる。
