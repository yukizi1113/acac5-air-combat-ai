# 中級セミナーの助言への対応状況

「第５回空戦AIチャレンジ 中級セミナー」（書き起こし・資料）の助言を一つずつ確かめ、この取り組みでの扱いをまとめました。
状態の記号：✅ 対応済み、🔶 一部対応、⬜ 未対応（理由あり）、🆕 今回着手。

## 第1部：空戦AIと強化学習の基礎

| 助言 | 状態 | 対応・根拠 |
|---|---|---|
| 敵の真後ろ・やや高い位置から撃つのが基本 | 🔶 | 交戦ラボで実測しました：命中率は正対 0.96・側方 0.74・背面 0.34（目標が回避しない場合）。この仕様では、**高い位置からの正対遠距離射撃**が最も有利です（v13 以降の `hot_*`）。背面からの射撃はすり抜けた敵への対策（`leak_shot`）として実装済みです。 |
| 位置エネルギーを使うと射程が伸びる（下向きに撃つ） | ✅ | 攻撃高度 13.5 km、護衛機への射撃前に 15.5 km へ上昇（`loft_alt`、v10_loft／v15）。ラボで、射撃高度が 14.9 km に上がると射程は 74→80 km、命中率は 0.75→0.82 になりました。命中確率モデルの特徴量に高度差 `dz` を含めています。 |
| 高度が上がると旋回性能が落ちる。むやみに上がらない | 🔶 | 上昇は速度が十分なときだけ行います（`climb_v0` など）。低高度化は実戦で大きく負けました（adapt 1574）。旋回性能の表そのものはまだ使っていません。 |
| 燃料の概念がない（質量一定） | ✅ | 全速を基本にしています（推力の節約はしていません）。 |
| 旋回性能は高度・速度別の表（数式で閉じない） | ⬜ | ルールベースでは必要になっていません。強化学習の観測には高度・速度の絶対値を入れる予定です（`rl/rl_obs.py`）。 |
| 勝敗が遅れてしか分からない（信用割り当て問題） | ✅ | ルール主体で回避しました。戦術の選択だけを学習の対象にしています（下の HRL）。 |
| 「チャンスで撃つ」が偶然には起きにくい → 捉えたら撃つルールとの併用 | ✅ | 射撃管制はルールと命中確率モデル（LightGBM）で行い、学習の対象から外しています。 |
| A2C（Critic による局面評価） | 🆕 | 戦術選択の価値 Q(状況, 戦術) を、同じ種の反実仮想ロールアウトで直接推定します（下記）。対戦途中の局面評価（Critic）は、実戦ログ 367 試合から学習する計画です。 |
| handyRL（Ray 並列、予想外れの再利用） | ⬜ | 計算資源が 2 コアしかなく、大規模な強化学習は回せません。助言にある handyRL の弱点「選ばなかった行動の結果は分からない」は、同じ種で対戦が決定的になることを利用して補います。 |
| DeepSets（機数可変・順序なし） | 🔶 | ルール側はセンサ融合で集合として扱っています。IRST 航跡の順序不変化（暫定ルール 2）にも対応しました。NN を作るときは `rl/` で採用予定です。 |
| 過去のレーダ状態を使う | ✅ | EKF 追跡と記憶航跡（src=3）。失探後も推定位置を保持し、迎撃・すり抜け対策で使っています。 |
| MWS は向き（近づいているか）も見る | 🔶 | MWS が出すのは方位だけです。ラボの結果は次のとおりで、どの回避機動も被命中率はほぼ同じでした（警報は命中の約 5 s 前）。<br>・回避の効果が小さい<br>・効くのは警報の前に背を向けること（脅威時計）<br>このため、方位の変化率による選別は優先度を下げました。 |
| 極座標（自機基準の方位・距離・高度差） | ✅ | 射撃・回避の判断は、すべて自機基準の相対幾何（アスペクト、オフボアサイト、距離、高度差）で行っています。 |
| HRL（作戦をルールで作り、選択を学習） | 🆕 | 下記の「戦術選択」で実施します。助言にある「ルール作戦が意図どおり動くかの検証が難しい」は、実戦ログ（毎秒の行動コード）とトレースで確認しています（例：守備機が逃げていたのを発見）。 |

## 今回着手：相手の型の推定 ＋ 戦術選択（HRL の上位層）
1. **反実仮想ロールアウト**：同じ種なら対戦は決定的なので、200 s までは全く同じ展開になります（arm 0 と v15 が試合単位で一致することを確認済み）。200 s で次の 5 戦術に分岐させ、それぞれの得点を比べます。
   - 0：現状維持（守備機 1）
   - 1：守備機 2
   - 2：守備機なし
   - 3：全機守備
   - 4：全機突撃
2. **相手の型の特徴量**：自機・味方の観測だけから作ります（`opp_features`）。
   - 自陣護衛機へ向かう敵の数
   - 追尾中の敵の数
   - 敵の平均 x・最前方の x
   - 敵の高度
   - 敵の速度
   - 自陣護衛機に最も近い敵の距離
   - 撃墜数・被撃墜数
3. **戦術選択の方策**：特徴量 → 各戦術の得点を線形モデル（標準化＋リッジ回帰）で予測し、最大のものを選びます（`arm_policy`）。
   - 6 種の相手 × 16 種で学習し、交差検証で評価します。
   - 実戦ログの特徴量分布とも照合します。
