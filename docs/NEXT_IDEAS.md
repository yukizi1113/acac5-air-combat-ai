# 圧倒的に強いモデルに向けて次に試すべきこと

優先度は、これまでの診断（docs/FINDINGS.md）との対応の強さで並べています。裏付けの弱い探索案は末尾に分けました。

## A. 評価系（最優先：今の最大のボトルネック）

診断：16試合の比較は ±0.1 ぶれます。同じ変更でも種の組で結論が反転し、局所の順位は実戦と一致しません。改良案の良し悪しを見分けられないことが、いま一番の制約です。

1. **計算資源を増やして種数を桁で増やす。** 2コアでは約120試合/時です。1候補の判定（SE 0.03）に250試合以上かかります。
   - `tools/run_matches.py` はプロセス並列なので、そのままコア数に比例して速くなります。
   - 手元PCやクラウドの多コア機で `--workers N` を使ってください。
2. **実戦に似た多様な対戦相手リーグを作る。** 自前の同系統エージェントだけでは偏ります。次を入れて、実戦スコアが既知の提出物（v7, p2, v9b, pk, adapt）の順位を再現できるか検証し、重みを決めてください。
   - 配布 HandyRL サンプルを数時間学習させた NN エージェント
   - 高高度型（15–16 km）
   - 早撃ち型
   - ベンチマーク Fixed / Random
   - 再現できないリーグは使わないこと。
3. **実戦の2枠を A/B 試験に使う。** 選択したモデルだけが実戦の対戦を積みます。
   - 「現最良」と「候補」を同時に選択し、1–2日ずつ比べてください。
   - 初期格付けの点数で判断しないこと。

## B. 戦闘機戦（勝敗を決める）

診断：勝敗は戦闘機戦の消耗で決まります。被撃墜の約2/3は撃ち返していない相手からです。ラボでは「被射撃から10–20 s以内に背面化すれば被命中 0–0.12」とわかりました。

1. **脅威時計の精密化（最有望）。** いまは「正対の敵が45 km以内に入って6 s」で一律に離脱しています。次の3つを各（自機, 敵機）組ごとに計算し、撃つ・誘導を続ける・離脱するを決めてください。
   - 相手の最速の射撃時刻（相手の射程正規化 rn_e と Pk から推定）
   - その弾に対する背面化の期限（ラボ表、または仮想シミュレータで逆算）
   - 自弾の SELF 到達時刻
   - 「自弾が SELF に達するまで誘導しても期限に間に合う」ときだけ誘導を続けます。この判定は相手のアルゴリズムに依存しない物理なので、非推移性に強いはずです。
2. **データリンク誘導の組織化。** 射撃機は撃った直後に背を向け、後方 15–25 km の僚機が照射を続けます（ラボで 15/16 命中）。dl_drag の実装は照射可否を幾何だけで推定していて不十分でした。
   - 実際にチーム航跡が維持されているか毎時刻確かめ、切れたら照射役が機首を向け直してください。
   - 編隊を「射撃役＋照射役」の対で組んでください。
3. **探知の改善。** 被撃墜のかなりの割合で、撃墜者がレーダ航跡になく IRST のみでした。
   - IRST 方位へレーダを向ける小刻みな首振り（ACAC4 の Spakona が有効と報告）を試す。
   - 航跡確立（10回中6回）を早める。
   - RCS の小さい機体を前に出す。
4. **すり抜け対策。** 後方へ抜けた敵機を記憶航跡で追い、後方射撃（RTail 内）をする。
   - `leak_shot` の実装はあります。
   - 前線の数を減らさない位置取り（中間に1機の掃討役）も候補です。

## C. 護衛対象機のレース

診断：p2（早撃ち）が実戦で最良で、到達の遅れ（中盤の後退・降下）が大きいことがわかっています。

1. **最早撃破時刻の計画。** 各機の性能（最高速度・推力スケール・残弾）と敵護衛機の周回予測から、「発射時刻＋飛翔時間」が最小になる射撃役・経路・発射点を選んでください。
   - 発射点は、RTail 円に最短で入る点です。
   - 飛翔時間は esc_lab の表から引けます。
2. **二段撃ち。** 遠距離（低Pk）の初弾と、80 km 以内（高Pk）の次弾を、別機から時間差で撃ちます。初弾が外れても追撃が早くなります。命中率の減点とのトレードオフは得点式で評価してください。
3. **攻撃役は中盤で後退させない（rush）。** ただし MWS 回避と脅威時計は残し、降下しない背面離脱にする。

## D. 相手に合わせた戦法選択（非推移性への対応）

- 開始150 s の観測（敵の高度分布、前進速度、迎撃に来るか護衛機へ直行するか）から相手の型を推定し、実戦で安全とわかっている戦法群の中から対抗策を選んでください。ACAC4 の3位はメタ選択ヘッドで改善しています。
- 低高度化は実戦で大きく不利でした（adapt 1574）。候補から外してください。

## E. 学習（計算資源が確保できる場合）

- 上位方策（5 s ごとのオプション選択＋射撃モード、rl/ に実装済み）を、最良のルール（p2 または脅威時計版）からの模倣で初期化してください。
- その後 PFSP リーグ（ルール版の各凍結版、早撃ち型、高高度型、過去の自分）で PPO を回し、報酬は勝敗中心にしてください。
- ACAC4 の上位は数十万エピソード（数日〜1週間）を使っています。2コアでは非現実的で、多コア環境が前提です。
- 学習で見つかった行動（射撃前上昇、すり抜けなど）は、ルール側に移植して検証してください。

## F. 裏付けの弱い探索案

- 自陣の護衛対象機に近い空域へ、敵の到達経路を予測して先回りする位置取り（ACAC4 の Spakona の事前転回）。
- 弾数の多い機体を囮にして、相手に弾を浪費させる。
- 引分（0.5）を狙う防御的終盤（勝てない状況で時間切れに持ち込む）。

## G. 暫定ルール対応

- シミュレータ更新後は、IRST 航跡の匿名ID・並び順の仕様が変わる可能性があります。fusion.py の継続対応付け（匿名IDの維持）を再検証してください。
- 判断に使う情報は、自機・味方機の観測（センサ航跡・データリンク）と時刻・ルールなどの公開情報に限ってください（docs/COMPLIANCE.md）。
